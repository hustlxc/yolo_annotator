          nnext image
          pprevious image
          ccycle to the next class
          1 – 9select class N directly
          dragdraw a box with the active class — at any zoom level
          drag a boxmove that box
          Space + dragpan the view
          Alt + dragpan the view
          h or the ✋ buttonpan mode: drag anywhere to move the view (Esc leaves it)
          clickselect a box; click empty space to deselect
          c / Crelabel the selected box (or choose the next class to draw with)

          ssave now (saves are automatic)
          + / −zoom in / out
          0 or the % buttonfit the image to the window
          wheelzoom at the cursor; Shift + wheel scrolls
          ?toggle this panel
          Escleave pan mode, or save and quit
